# 评价口径与字段

## 数量与集合

共登记999个模型，19个未通过源资格检查，评价分母为980。登记表中保留全部999个ID及源资格。模型来源及初选过程不能由目录或历史分组标签推断；初选1000与实际登记999之间的差异未在本批记录中得到解释。

可读输出指可以加载为纯四边形网格。严格有效使用冻结的结构与几何检查：包括闭合性、连通性、流形与拓扑一致性、退化和近奇异单元、自交等检查。可读输出数量不等于严格有效数量，正角质量诊断也不能单独替代完整检查。

源资格用于确定评价输入；严格有效用于判断生成输出，两者是不同的检查对象。

## 误差

| 指标 | 归一化 | 含义 |
|---|---|---|
| `feature_RMS_h` | 完整源特征RMS除以固定h | 未施加为约束和未匹配的源特征仍参与评价 |
| `surface_RMS_bbox` | 表面RMS除以源包围盒对角线 | 衡量表面近似误差 |
| `CD_squared_bbox` | 平方Chamfer距离除以源包围盒对角线平方 | 是平方距离口径，不能当作未平方距离 |
| `HD_sampled_bbox` | 采样Hausdorff距离除以源包围盒对角线 | 是采样/离散查询估计，不是精确连续Hausdorff距离 |

h按冻结源尺度定义；同一模型所有配置共享同一h与源参考图。阈值达标要求`strict=True`且`feature_RMS_h≤阈值`。仅有较低误差的无效网格不计达标。

特征指标使用冻结参考图main层的全部源特征边，并按源长度加权；其他辅助层不混入该指标。main层参考不会随D的约束选择或R的匹配结果缩减。

连续主表使用4个主配置共同可读的832个模型，包含无效网格，每个模型等权。另报告480个共同严格有效模型。相对变化率在明确的配对集合内计算，不把不可读输出填零、不删除尾部大误差。

## `data/per_model.csv`

每行是一个配置在一个源模型上的最终输出。8个配置各980行，总7840行。字段保留原始数值精度，缺失值为空字符串。

| 字段 | 类型或约定 |
|---|---|
| `id` | 模型ID，按字符串处理 |
| `arm` | 配置编号，含义见`data/configurations.json` |
| `readable` | True/False |
| `strict` | True/False，冻结严格有效判定 |
| `quad_sha256` | 所报告网格的SHA-256；没有网格时为空 |
| `actual_Q` | 实际四边形面数；没有可读网格时为空 |
| 四项误差字段 | 归一化误差；缺失时为空 |

主表配置为`native_B`、`native_B_R`、`self_G_fallback`、`self_G_R_fallback`，共3920行。其余4个是历史诊断来源及旧选择规则对照，不是另一轮参数实验。

公开导出移除了机器相关的`quad_path`列。源网格、源参考和输出网格的身份散列保留；这一处理不修改几何、评价值或失败状态。

## 复算与原始执行的区别

`scripts/verify_results.py`从已发布逐模型数据独立计算数表，核对SHA与登记集合。它验证数据整理过程，不重新执行冻结几何检查或后端。原始执行的身份审计摘要单列于`provenance/original_run_audit.json`。
