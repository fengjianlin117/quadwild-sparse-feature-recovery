# 稀疏特征约束与固定连接恢复：QuadWild 论文资料

这份资料用于撰写当前版本的论文，收录2026年11月6日完成的QuadWild自身输出诊断实验、D/R整体消融、论文主张与当前方法说明。

**当前版本：QuadWild 自身输出初始诊断＋D＋固定连接恢复 R。**

## 论文主张

> 我们将可行性与保真度解耦：以稀疏特征约束提高生成可靠性，并维持布局的特征意识；随后，以完整源特征网络为目标，在固定连接下完成几何恢复。

论文重点是提高严格有效且特征准确的四边形网格输出数量。D负责约束调整与重新生成，R负责有效父网格上的几何恢复。

## 主结果与整体消融

分母统一为980个源合格模型。F表示完整源特征RMS/h；所有特征阈值列同时要求严格有效。

| 配置 | 可读输出 | 严格有效 | F≤0.01 | F≤0.025 | F≤0.05 | F≤0.1 |
|---|---:|---:|---:|---:|---:|---:|
| B：原生QuadWild | 832 | 480 | 178 | 364 | 435 | 467 |
| B＋R | 832 | 480 | 256 | 451 | 474 | 479 |
| B＋D | 858 | 549 | 178 | 366 | 445 | 490 |
| B＋D＋R | 858 | 549 | 276 | 496 | 535 | 547 |

D将原生失败组中的69个模型变为有效。这69个模型中，F≤0.05达标数由R前10个提高到R后61个；原生有效组接R后474个达标，因此完整方法的535个达标输出为474＋61。

## 本地核验

在仓库根目录执行：

```bash
python scripts/verify_results.py
```

核验脚本读取本包数据，不调用QuadWild，不重新生成网格。它验证数表复算与文件一致性。原始网格和完整后端运行环境不随这份写作资料包发布，因此该脚本不是端到端网格生成复现入口。

本包只收录上述主实验和必要对照，不含后续参数分析、未实施方法方案或内部组件消融。当前方法的固定参数记录于[实验协议](protocol/experiment.json)。
